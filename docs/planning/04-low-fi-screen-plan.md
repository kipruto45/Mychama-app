# 04. Low-Fidelity Screen Plan

## Auth Screens

### Splash
- brand mark
- loading indicator
- auth bootstrapping logic

### Onboarding
- 3 swipe cards
- value propositions
- primary CTA (`Get Started`)
- secondary CTA (`Sign In`)

### Login
- identifier input
- password input
- remember/session option
- links (`Forgot password`, `Register`)

### Register
- full name
- email/phone
- password and confirm
- terms checkbox

### OTP Verification
- OTP input cells
- countdown and resend
- verification state feedback

### Forgot/Reset Password
- identifier form
- token + new password form
- completion confirmation

## Main Screens

### Home Dashboard
- greeting + active chama switcher
- metric cards (wallet, pending, loans, penalties)
- trend snapshot
- quick actions
- recent activity feed

### Chama List
- searchable list
- filter chips (all, active, archived)
- empty state with create CTA

### Chama Detail
- chama hero card
- progress to group goal
- members preview
- contribution status summary
- shortcuts to payments, meetings, reports

### Payments
- segmented view (pending, completed, failed)
- payment list with amount/date/status
- CTA to contribute

### Meetings
- upcoming and past tabs
- meeting cards with date/time/location
- create meeting CTA for authorized roles

### Notifications
- unread/read grouped list
- mark all as read action
- notification tap deep-links to source

### Profile
- profile card
- KYC status badge
- account/security actions

### Settings
- notification toggles
- privacy/security
- support/about
- logout action

### AI Chat
- conversation list
- prompt composer
- quick prompt chips
- typing/loading state with streamed feel

## Detail and Form Screens

### Make Contribution
- amount + method + note
- transaction confirmation sheet
- success receipt transition

### Payment Detail / Receipt
- status timeline
- method and reference
- download/share receipt action (phase 2)

### Member List / Requests / Invite
- member role badges
- request approval actions
- invite link generation

### Create Meeting / Meeting Detail
- structured agenda input
- attendance toggles
- minutes and resolutions capture

### Finance Details
- transactions list with filters
- loan details and repayment status
- penalties summary

## Required UI States Per Screen

- loading state
- empty state
- error state with retry
- success state feedback
