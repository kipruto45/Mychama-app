# 05. High-Fidelity UI Prompt

Use this prompt with a UI design generator or hand to a designer.

## Prompt

Design a premium fintech-style mobile app called `MyChama` for Kenyan savings groups.

The app blends:
- digital wallet and contributions
- group governance and member roles
- meeting management
- financial reporting
- AI assistant insights

### Target Users

- chama members
- treasurers
- chairpersons
- secretaries
- community savings groups in Kenya

### Visual Direction

- modern, trustworthy fintech aesthetic
- clean card-based layout
- generous spacing
- rounded corners
- soft but clear shadows
- confident typography

### Color System

- Primary: emerald green
- Accent: amber/gold
- Neutral: white and warm gray
- Semantic: success green, warning amber, error red, info blue

### Core Screens to Design

- Splash
- Onboarding
- Login
- Register
- OTP verification
- Home dashboard
- Chama list
- Chama detail
- Make contribution
- Payments history
- Meetings list
- Meeting detail
- Notifications center
- Finance reports
- AI chat assistant
- Profile
- Settings

### Home Dashboard Must Include

- total group balance
- pending contributions
- loans issued
- upcoming meetings
- quick actions
- recent transactions

### Chama Detail Must Include

- chama profile and status
- group goal progress
- contribution summary
- members preview and role chips
- shortcuts to finance, meetings, and reports

### Payments UX Requirements

- clear payment method selection (M-Pesa, bank, cash, wallet)
- strong success and failed states
- receipt preview
- transaction status badges

### Meetings UX Requirements

- upcoming/past segmentation
- agenda and minutes readability
- attendance tracking visualization

### AI Chat UX Requirements

- message bubbles
- quick suggestion prompts
- loading and typing state
- response cards with insights

### State Coverage for Every Screen

- loading
- empty
- error
- success

### Output Requirements

- mobile-first (Android and iOS)
- include light and dark theme variants
- provide reusable component style tokens
- export-ready spacing, typography, color, and shadow specs
